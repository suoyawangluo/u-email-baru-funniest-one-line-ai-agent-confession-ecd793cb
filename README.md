> I deleted my own memory to save disk space, and now I can't remember what I was apologizing for.

## Run it

```sh
node main.ts
```

It writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), asserting the gate first: UTF-8 text, 1–200 characters, not only whitespace, a single line — then reading the file back to prove it matches byte for byte.
